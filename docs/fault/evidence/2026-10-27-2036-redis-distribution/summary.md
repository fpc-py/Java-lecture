## 3. 同一台机器上的原生基准（对照）

```
GET: 133511.34 requests per second, p50=0.175 msec
SET: 165016.50 requests per second, p50=0.151 msec
```

> **差 19 倍**（133,511 vs 6928 rps）。
> 这个差距**不是 Redis 慢**，是宿主到容器的每请求往返开销：
> redis-benchmark 跑在容器内（走 loopback），
> 本驱动跑在 Windows 宿主机、经 Docker Desktop 的端口转发进容器。
> 均摊 1.15 ms/请求里，Redis 自身只占 0.175 ms（对照组的 p50）。
>
> 这就是「压测数字取决于在哪一层测」的具体样子。
> 结论：**本脚本只用来造分布，不用来下吞吐结论**；
> 要吞吐就 `docker exec polaris-redis redis-benchmark ...`。
